## P2: deferred (boundaries only)

Cloud sync (outbox and operation ids already exist in `commands`), team roles, customer portal links, automated messaging provider, AI/voice/OCR input, cross-currency settlement, monetization. See `docs/release-checklist.md` → Deferred.

## Validation gates

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, `npm run bench`. Browser checks run in the local preview. Device-only checks stay **pending** until run on real devices.
